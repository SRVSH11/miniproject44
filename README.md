StudyCircle – Student Community Platform

📌 About the Project

StudyCircle is a student community platform designed to help students connect, communicate, and learn together. It provides a common space where students can ask questions, share study materials, participate in discussions, and help each other academically.

The main aim of StudyCircle is to create a collaborative learning environment where students can easily exchange knowledge and solve academic doubts.

🎯 Objectives

- To provide a platform for students to interact and collaborate.
- To make doubt solving easier through student discussions.
- To allow students to share notes and learning resources.
- To create subject-based communities for knowledge sharing.
- To encourage collaborative learning among students.

✨ Key Features

- Student Accounts: Students can create accounts and maintain their profiles.
- Community Feed: View posts and discussions shared by other students.
- Doubt Solving: Ask academic questions and receive answers.
- Notes Sharing: Share study materials and notes.
- Discussions: Participate in subject-related discussions.
- Student Communities: Connect with students having similar academic interests.

⚙️ Installation and Setup

1. Clone the repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder:
   
   cd YOUR_PROJECT_FOLDER

3. Install dependencies:
   
   npm install

4. Configure the required environment variables using the provided ".env.example" file.

5. Start the development server:
   
   npm run dev

6. Open the local URL displayed in your terminal to access StudyCircle.

🚀 Deployment

The project is deployed using Vercel. The GitHub repository is connected to Vercel to build and deploy the application.
